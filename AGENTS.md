# AGENTS.md

Instructions for coding agents working in this repo.

walgo is a Go CLI (Cobra) that builds Hugo/static sites and deploys them to Walrus decentralized storage, with optional SuiNS domain linking. It also ships an optional Wails desktop app in `desktop/` that drives the same code through `pkg/api`.

## Layout

- `main.go`, `cmd/`: Cobra commands (`launch`, `deploy`, `deploy-http`, `projects`, `domain`, `ai`, `setup`, `doctor`, ...).
- `internal/walrus/`, `internal/deployer/`: on-chain deploys through the external `site-builder`, `walrus`, and `sui` binaries; `internal/deployer/http` is the free HTTP publisher path.
- `internal/sui/`: wallet and network management by shelling out to the `sui` CLI, including address import from a private key or mnemonic.
- `internal/ai/`: AI content generation; provider API keys live in `~/.walgo/ai-credentials.yaml`.
- `internal/hugo/`, `internal/optimizer/`, `internal/compress/`, `internal/obsidian/`: site build, minification, Brotli, Obsidian import.
- `internal/config/`, `internal/projects/`: `walgo.yaml` config and the local project database.
- `pkg/api/`: the API the desktop app binds to.
- `desktop/`: Wails app (separate Go module) with a React + Vite frontend in `desktop/frontend/`; `desktop/frontend/wailsjs/` is generated by Wails.
- `docs/`: user and contributor docs, including `docs/ARCHITECTURE.md` and `docs/CONTRIBUTING.md`.

## Commands

- Build: `make build`
- Test: `make test` (race detector + coverage), `make test-short` (faster)
- Format, vet, test: `make check`; lint: `make lint` (golangci-lint)
- Desktop: `make desktop-dev`, `make desktop-build`; frontend tests: `cd desktop/frontend && npm test`

CI runs `gofmt -s`, `go vet ./...`, and `go test -race` on Go 1.24.

## Care points

- On-chain deploys spend real WAL/SUI. Use testnet unless mainnet is explicitly requested, and never run deploy commands as a test.
- Never log or print private keys, mnemonics, or AI API keys.
- CLI command names, flags, and `walgo.yaml` keys are a public interface. Keep them backward compatible.
